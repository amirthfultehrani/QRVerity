# 0005. Canonical SVG Renderer & Pixel-Snapped Rasterization Pipeline

This document specifies PureQR's visual representation engine, SVG security model, quiet zone rules, and pixel-snapped rasterization pipeline.

---

## 1. Core Architecture Invariants

> [!IMPORTANT]
> **HARD INVARIANT: Canvas is NOT a second QR renderer.**
> All visual representations (SVG export, PNG export, UI preview, scanning verification, and print export) MUST derive directly from the SAME canonical rendered SVG output generated by `renderQrSvg`. Canvas is strictly a downstream rasterization target and must NEVER independently redraw QR modules from a `QrMatrix`.

---

## 2. Input Contracts & Requirements

The SVG renderer (`renderQrSvg`) accepts domain objects only:

```ts
renderQrSvg(
  matrix: QrMatrix,
  structure: QrStructureMap,
  options: QrRenderOptions
): QrRenderResult
```

### Invariants:

- The renderer MUST consume both `QrMatrix` and `QrStructureMap`.
- `matrix.size` MUST equal `structure.size` and `matrix.version` MUST equal `structure.version`.
- The renderer MUST NOT import Preact, Nayuki, or read global application state.
- The renderer MUST NOT recompute QR geometry independently.

---

## 3. Quiet Zone Policy & Geometry

- **Hard Minimum**: Quiet zone MUST be at least **4 modules** (`quietZoneModules >= 4`). Values less than 4, non-integers, `NaN`, `Infinity`, or negative numbers are strictly rejected with a `RangeError`.
- **Coordinate Model**: Geometry operates in module-space coordinates (`viewBox="0 0 totalModules totalModules"`), where `totalModules = matrix.size + (2 * quietZoneModules)`.
- **Origin Offset**: Matrix coordinate `(x, y)` is rendered at module position `(x + quietZoneModules, y + quietZoneModules)`.

---

## 4. SVG Generation Strategy & Security Rules

PureQR generates clean, ultra-compatible SVG using basic element primitives (`<svg>`, `<rect>`, `<g>`).

### Geometry Strategy

- Background: Single opaque `<rect width="totalModules" height="totalModules" fill="background"/>` covering full symbol and quiet zone.
- Dark Modules: Exact `1x1` `<rect x="modX" y="modY" width="1" height="1"/>` elements grouped inside `<g fill="foreground">`.
- Light Modules: Represented implicitly by the background fill (not rendered as foreground elements).

### Security Constraints

Canonical SVG strings MUST NOT contain:

- `<script>` or executable code
- Inline event handlers (`onload`, `onerror`, `onclick`, etc.)
- `<foreignObject>` tags
- External resource links (`http:`, `https:`, `data:`, `url(...)`)
- Embedded stylesheets or CSS class attributes
- Dynamic CSS variables (`var(...)`)

### Safari Compatibility Rule

To prevent Safari SVG canvas rasterization bugs and CORS security tainted canvas exceptions:

- SVG uses inline fill attributes (`fill="#RRGGBB"`), not CSS classes or external stylesheets.
- SVG contains zero external resources or image tags.

---

## 5. Color Validation & Normalization

Colors MUST be validated by `normalizeHexColor` before rendering:

- Allowed formats: `#RGB` and `#RRGGBB` hex strings.
- Short hex (`#RGB`) is automatically canonicalized to uppercase `#RRGGBB`.
- Expressions such as `url(...)`, `var(...)`, `rgb(...)`, or CSS style injection strings are strictly rejected.

---

## 6. Integer Pixel-Per-Module Snapping Policy

To eliminate sub-pixel anti-aliasing artifacts during rasterization, PureQR enforces integer module snapping via `planRasterSize`:

$$\text{pixelsPerModule} = \max\left(1, \text{round}\left(\frac{\text{requestedSizePx}}{\text{totalModules}}\right)\right)$$

$$\text{actualSizePx} = \text{pixelsPerModule} \times \text{totalModules}$$

- **Snapping Guarantee**: `actualSizePx % totalModules === 0`.
- Module boundaries map 1-to-1 to integer display pixel boundaries.

---

## 7. Browser Rasterization Lifecycle

The browser rasterizer (`rasterizeQrSvg`) executes the following deterministic lifecycle:

1. **Parse & Plan**: Extracts `totalModules` from canonical SVG `viewBox` and computes integer pixel plan via `planRasterSize`.
2. **Canvas Initialization**: Creates `HTMLCanvasElement` sized to `actualSizePx x actualSizePx` with `ctx.imageSmoothingEnabled = false`.
3. **Blob URL Creation**: Converts canonical SVG string into an in-memory `Blob` URL (`image/svg+xml;charset=utf-8`).
4. **Image Loading**: Loads SVG Blob into an HTML `Image` object.
5. **Draw & Cleanup**: Draws `Image` onto Canvas, revokes the Blob URL (`URL.revokeObjectURL`) inside a `finally` block, and extracts raw `ImageData`.
