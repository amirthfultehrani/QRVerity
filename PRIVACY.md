# Privacy Policy

QRVerity is engineered from the ground up for maximum user privacy.

---

## Technical Privacy Guarantees

1. **Local Browser Processing**: All QR payload data, appearance configurations, local logo processing, SVG generation, PNG rasterization, and optical worker verification occur exclusively inside your web browser environment.
2. **No Application Backend**: QRVerity operates without an application backend, database, API endpoint, or external verification service. QRVerity itself does not receive, log, store, or transmit your QR code inputs or uploaded logo files.
3. **Zero Telemetry / Zero Analytics**: QRVerity contains no analytics scripts, tracking pixels, crash reporting tools, or third-party monitoring libraries.
4. **Static Hosting Model**: The static web hosting provider (such as GitHub Pages) necessarily serves the application's HTML, JavaScript, CSS, and asset files to your browser via standard HTTP web server requests. Once loaded in your browser, application interaction, image sanitization, and QR code processing remain strictly client-side.
